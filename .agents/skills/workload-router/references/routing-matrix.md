# Routing matrix

| Characteristic | Fast | Standard | Deep |
|---|---:|---:|---:|
| Local and reversible | Yes | Possible | Rare |
| Multi-file | Rare | Yes | Yes |
| Public contract/data migration | No | Rare | Yes |
| Security or permissions | No | Possible | Yes |
| Intermittent root cause | No | Possible | Yes |
| Read-heavy independent questions | Optional | Parallel | Parallel |
| Overlapping writes | Single writer | Single writer | Single writer |
| Runtime proof | As needed | Usually | Required when feasible |
