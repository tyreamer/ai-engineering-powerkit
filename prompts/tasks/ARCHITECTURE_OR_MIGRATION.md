# Evaluate an Architecture Change or Migration

Apply Prompt Preflight, Repository Cartographer, Change Impact Analysis, and Migration Planner. Add Security and Privacy Review or API Contract Guardian when the affected boundaries require them.

Map the current system before proposing a target state. Identify consumers, data ownership, contracts, trust boundaries, operational dependencies, deployment order, compatibility, observability, and rollback. Separate repository evidence from inference.

Compare only credible options and recommend the smallest reversible architecture that supports the desired outcome. Do not silently select a vendor, change a public contract, or accept caller-provided identity or permissions. Ask only about material choices that remain unresolved after inspection.

Produce an ordered vertical migration rather than a big-bang rewrite.
